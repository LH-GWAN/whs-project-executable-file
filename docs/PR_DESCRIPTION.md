# PR 제목

분석 무결성·GPS 표시/통계·재생 탐색 오류 수정

# PR 본문

GPS 공백으로 되감으면 미래 좌표·속도가 남고, 제외한 이상치가 속도 통계에 포함됩니다.
사본 SHA-256 검사는 분석 완료 후에만 실행되어 불일치 사본으로 엔진이 실행될 수도 있습니다.
이 변경은 해당 정확성 문제와 9/21 실행 검토의 재생/조작 결함을 수정합니다.

## 변경

- 전후방 사본 해시를 엔진 실행 전에 검증하고 사건 생성/저장 실패를 정리합니다.
- 현재 시각 이하 GPS 조회, 체크섬·신뢰도·유한값 검사, 그래프/통계 공통 필터를 적용합니다.
- 재열기 프라이밍 타이머를 취소 가능하게 하고 키보드 탐색, 오류 안내, 오디오,
  짧은 후방 영상 범위 처리를 보완합니다.
- F_1/R_1 후보, 최소 한 개 분석 선택, WebGL 실패 안내, 최신 지도 상태 복원을 보완합니다.
- no_gps와 엔진 실패를 구분하고 재열기 상태·경고를 보존합니다.
- GUI/PDF에 상태·경고·복구·GPS 검증 정보를 표시하고 PDF 표본화를 개선합니다.

원본 vendor snapshot은 변경하지 않습니다. 기존 coordinates.csv의 신뢰도 필드를
어댑터에서 연결합니다. CSV 원본을 변경하거나 실패 측정값을 삭제하지 않습니다.

## 검증

- `python -m pytest -q tests`: **34 passed** (Python 3.12 / PySide6 6.11.2 / Linux).
- 실제 Qt 디코더: 3회 재열기 첫 재생, 방향키 탐색 및 프레임 timestamp, 프라이밍 중
  3.5초 탐색 유지, 짧은 후방 범위 밖 정지와 되감기 복구.
- 실제 subprocess 엔진: 합성 H.264/AAC MP4의 no_gps 분석과 History 재열기.
- 회귀: 미래 GPS 선택/속도999 이상치/해시 불일치/저장 실패/기존 폴더 보존/신뢰도 CSV.
- WebGL 생성 예외를 실제 HTML 스크립트의 Node VM 시험으로 확인.
- Python 컴파일 및 `git diff --check` 통과.

Qt 위젯/디코더 시험의 지도는 대체 객체입니다. 실제 Windows EXE, 온라인 카카오맵,
실기종 AVI/JDR·4K, 스피커 청감, PDF 인쇄 레이아웃은 미검증입니다.

추가 실영상 검증: 60.06초 MP4에서 수정 전/후 모두 600행·GPS60개·엔진 종료0.
수정 전 0초/0.39초의 좌표·속도 잔류, 키보드 위치 불일치, 초기화 중 탐색/재생
덮어쓰기를 재현했고 수정 후 해소를 확인했습니다. 일반적인 재열기 첫 재생은 원본도
정상이었습니다. 계측값과 범위는 `docs/RUNTIME_VERIFICATION.md`를 참고하세요.

## 범위와 남은 작업

지도 클릭→영상, 중복 방문 후보 선택, 표 필터/그래프→영상, 전용 슬랙 화면,
History 검색/상태 열, JDR 변환 통합은 포함하지 않습니다.
신뢰도 검사 강화로 기존 통계가 달라질 수 있습니다. 평균은 유효 고유 GPS 측정의
산술평균이며 시간 가중 평균이 아닙니다. 상세 대조는 `docs/REVIEW_20260923.md` 참고.
