# 수정본 추가 실행 검증

검증 대상: 원격 수정본 83bd897(로컬 487cd36과 파일 트리 동일), 이후 Home 정지 보완.

## 판정

실행 중 Home으로 이동해도 재생이 계속되는 문제를 추가 발견했다. ui/main_window.py의
_show_home()에서 TrackerTab.stop()을 호출하도록 수정했다. 원래 Home 경로에 정지가
없었으며, 이번 오디오 연결로 숨겨진 재생음이 이어질 가능성도 있어 함께 보완했다.
수정 후 실제 메인 화면의 History 재열기 3회, 각 3개 탭 전환, 재생 후 Home 복귀가
모두 통과했다. 첫 실행 지도 설정 대화상자만 생략했으며 실제 지도 위젯을 사용했다.
Qt 콜백 예외 0건. 합성/실영상·통제 입력 시험 범위에서는 추가 회귀를 발견하지 못했다.

## 실행 증거

- pytest: 40 passed. Python 3.12.14, PySide6 6.11.2, Linux offscreen.
- 실제 1440p MP4: 60.06초, 600행/GPS 60개, 엔진 종료0, 상태 ok.
- 40.7/1.5/0/0.39/10초 탐색: 현재 이하 GPS 표시 및 실제 프레임 수신 일치.
- 방향키: 슬라이더/플레이어 모두3000ms. 재열기3회 모두 첫 재생 성공.
- 합성 2트랙 MP4: both→rear→front→both→단일 영상 전환. 활성 트랙/후방 해제 정상.
  두 트랙은 같은 영상 스트림을 복제한 것으로 실기종 2채널 검증을 대체하지 않는다.
- 합성 영상에서 무작위 탐색100회: 플레이어/슬라이더/속도 표시 일치.
- 손상 MP4 오류 후 정상 영상 로드/재생 복구, 배속·음소거·음량 객체 상태 정상.

- 기존 해시 불일치·저장 실패·신뢰도·이상치·no_gps·초기화 중 조작 시험 유지.
- 실제 로컬 지도 서버/Qt WebEngine: WebGL 없는 환경에서 새 오류 안내 표시.
  지도 오류 상태에서도 실제 ReportExporter의 PDF 저장 성공.
- 실제 보고서: 합성600행을200행으로 표본화하여 A4 6페이지 생성.
  첫/마지막 페이지 이미지 확인, 마지막600번 행 포함, 과도한 반복 생략행 없음.
- Python compileall 및 git diff --check 통과.

## 남은 제한

한글 폰트가 없는 이 실행 환경에서 PDF 한글이 네모로 출력된다. fc-list :lang=ko 결과가
비어 있고, 수정 전 ba69920도 같은 현상을 보였다. 신규 회귀로 판정하지 않았으며
한글 폰트가 설치된 배포 환경에서의 PDF 시각 검증은 여전히 필요하다.
현재 시험은 소프트웨어 영상 디코딩이다. 하드웨어 가속/음향 장치가 없어 실제 청감은
확인하지 못했다. 지도 정상 WebGL 렌더·온라인 카카오/주소 조회, Windows EXE,
실기종 AVI/JDR·다중채널 녹화물은 이 실행으로 검증하지 않았다.

개인 원본 영상, 실제 좌표, 사건 DB, 실영상 화면은 저장소에 추가하지 않았다.
