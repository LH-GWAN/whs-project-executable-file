## 결론과 집계 기준

9/21 실행 검토의 **결함 8개(F1–F8)** 기준으로 최신 main은 완전 반영 0개,
부분 반영 1개(F2), 미반영 7개였다. 이번 브랜치에서는 8개 모두 관련 코드를 보완했다.

## 수정 파일 선별

제품 코드 13개 파일을 수정했다. 고정된 `engine/vendor/`와 원본 분석 알고리즘은 수정하지 않았다.

- `core/pipeline.py`: 분석 전 해시 검사, 사건 생성 실패 정리, 재열기 상태와 경고 보존.
- `engine/engine_adapter.py`: 유효 좌표/신뢰도, CSV 신뢰도 연결, no_gps 구분, 출력 재사용 차단.
- `core/outliers.py`, `core/acceleration.py`: 유한값/정상 GPS 필터 및 (0,0) 처리.
- `ui/tracker_tab.py`: 시간 기준 조회, 재생 수명/키보드/오디오/오류/후방 범위.
- `ui/map_view.py`, `ui/web/map.html`: 과거 기반 방향, 지도 로딩 중 최신 상태만 유지, WebGL 오류 안내.
- `ui/analysis_view.py`: 사건 변경 source 해제와 분석 상태 표시.
- `ui/speed_tab.py`, `ui/location_tab.py`: 일관된 통계와 GPS 검증 표시.
- `core/video_pairs.py`, `ui/case_info_dialog.py`: 번호 붙은 후방 후보와 빈 분석 선택 차단.
- `report/report_builder.py`: 균등 표본, 경고·복구·검증 요약, 속도 통계, 원본 CSV/생성시각.

## 실행 검증

환경: Python 3.12, PySide6 6.11.2, pytest 9.1.1, Linux offscreen Qt, FFmpeg, Node.js.
이 환경의 누락된 Xtst/xkbfile 공유 라이브러리는 임시 디렉터리에서 로드했다.

```bash
python -m pytest -q tests
python -m compileall -q core engine ui report storage
git diff --check
```

최종 테스트 실행 결과는 PR 설명의 기록 참조. 테스트 파일:

- `tests/test_review_regressions.py`: GPS/통계/무결성/롤백/CSV/위젯/표본화 회귀.
- `tests/test_media_smoke.py`: 실제 Qt H.264/AAC 디코더의 재열기·탐색 프레임,
  프라이밍 충돌, 짧은 후방 복귀, 실제 subprocess 엔진 no_gps 분석/History 재열기.
- `tests/test_map_script.py`: 실제 HTML의 JavaScript를 Node VM에 넣고 Map 생성자 실패 확인.

디코더 시험은 지도·주소 네트워크를 격리한 실제 Tracker 위젯과 실제 QMediaPlayer를 사용한다.
프레임 timestamp도 확인하므로 position 값만 검사한 mock 시험은 아니다.
전체 MainWindow의 수동 작업 흐름, 실제 WebGL/카카오 지도 화면, 온라인 주소 지연,
Windows EXE, 실제 기종별 AVI/JDR, 4K·장시간, 실제 전후방 촬영 오프셋, PDF 인쇄 레이아웃은
미검증이다. PDF는 HTML 내용/이스케이프/표본 행 선택을 시험했다.

## 남은 기능과 적용 시 주의

지도 정상점 클릭/중복 방문 후보/QWebChannel/Location→영상 등 9/20 전체 기능 명세는
이 브랜치에 구현하지 않았다. 독립 기능으로 묶어 구현·시험할 사항이며, 이 수정의 완료로
계산하지 않았다. JDR 네이티브 변환 통합과 AI 기능도 이번 오류 수정에 추가하지 않았다.

기존 저장 결과에 신뢰도 원자료가 없으면 '미제공'으로 남는다. 원본 CSV가 없거나 불완전한
사건의 신뢰도를 새로 증명할 수는 없다. CSV 필터 정책이 강화되어 종전보다 유효 좌표·속도
통계가 줄 수 있다. GPS 수신 공백에서 직전 유효값을 보여주며 그 측정 시각을 툴팁에 표시한다.

전후방은 동일 상대 재생시각으로 맞춘다. 실제 촬영 시각 차이를 추측 보정하지 않는다.
오디오가 사건 내용에 필요하면 Windows에서 음소거/음량과 출력 장치를 별도로 확인한다.
